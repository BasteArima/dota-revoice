# Dota Revoice

Программа для любительской переозвучки героев Dota 2. Слушаешь оригинальную
реплику, записываешь свою (или подкладываешь файл — хоть голосовое из Telegram),
а программа собирает из этого мод, который игра подхватывает вместо озвучки Valve.

- все герои Доты с портретами — фразы программа достаёт из игры сама, без Source 2 Viewer;
- список фраз героя по категориям, поиск, заметки к фразам;
- звуки способностей героев и предметов — по способностям и предметам, с иконками;
- личности и автоматоны (Anti-Mage «Вэй», Axe-автоматон…) — своими карточками рядом с героем;
  фразы и звуки аркан и наборов — разделами у героя, их можно спрятать одной галочкой;
- волна оригинала и своей версии в одном масштабе, сравнение «оригинал → моя»;
- запись с микрофона: отсчёт 3-2-1 или «сначала прослушать оригинал»;
- обрезка тишины (сама или ручками на волне), громкость как в оригинале (LUFS) —
  у одной фразы или сразу у всех фраз героя, ползунок громкости, шумодав, тон голоса,
  дубли — всё без потерь, исходник не меняется;
- сборка пака, установка в игру и запуск Доты — в три шага; мод можно выключить
  и включить обратно одним переключателем, без пересборки;
- настройки: где игра, какую озвучку переделываем, где лежат файлы;
- интерфейс на русском и английском (переключается в настройках);
- обмен фразами с друзьями одним zip-файлом.

## Скачать

Готовые сборки — на странице [Releases](https://github.com/BasteArima/dota-revoice/releases).

**Windows.** Распакуй `DotaRevoice-…-windows-x64.zip` и запусти `DotaRevoice.exe`.
Программа не подписана сертификатом, поэтому Windows может показать «Система Windows
защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае».

**macOS.** Распакуй `DotaRevoice-…-macos.zip` и перетащи `DotaRevoice.app` в «Программы».
При первом запуске: правый клик по программе → «Открыть» → «Открыть» (она тоже без
сертификата Apple). Когда попросит доступ к микрофону — разреши.

**Linux.** Распакуй `DotaRevoice-…-linux-x64.tar.gz` и запусти `./dota-revoice`.
Нужна ALSA (`libasound2`) — на обычном десктопе она уже есть; PipeWire и PulseAudio
работают через неё. Steam находится и обычный, и из Flatpak. Для меню приложений
рядом лежит `dota-revoice.desktop` — поправь в нём путь и положи в
`~/.local/share/applications/`, а иконку `dota-revoice.png` — в `~/.local/share/icons/`.

При первом запуске программа спросит три вещи: где Дота (обычно находит сама), какую
озвучку переделываем (видны языки, скачанные в Steam) и где хранить фразы. По умолчанию
на Windows это папка `library` рядом с программой, на macOS и Linux — «Документы/Dota Revoice».
Всё это потом меняется в настройках (шестерёнка справа вверху).

Новые версии программа находит сама: сверху появится «Вышла новая версия» со ссылкой.

## Как пользоваться

1. **Выбери героя** на вкладке «Герои». Программа сама достанет его фразы из пака
   озвучки игры (в рабочую папку, `originals/`). У героев с пометкой «EN» нет озвучки
   на выбранном языке — оригинал у них английский, а твои фразы заменят его в игре.
   Звуки не из списка (дикторы, курьеры, своя выгрузка) — «Открыть свою папку…».
   Звуки способностей героя — переключатель «Способности» над списком фраз, звуки
   предметов — вкладка «Предметы».
2. **Записывай.** Выбери фразу, послушай оригинал (Space), нажми R или большую красную
   кнопку, скажи реплику, снова R. Тишина по краям и громкость подгонятся сами.
3. **«Сборка и установка»** → «Собрать пак» → «Установить» (Доту перед этим закрой) →
   «Запустить Доту». Новые фразы звучат в игре.

### Горячие клавиши

| Клавиша | Что делает |
|---|---|
| Space | оригинал |
| Ctrl+Space | моя версия |
| R | запись / стоп |
| C | сравнить: оригинал, потом моя |
| T | убрать тишину по краям |
| L | громкость как в оригинале |
| ↑ ↓ | предыдущая / следующая фраза |
| N | следующая незаписанная |
| Del | моя версия — в корзину |
| Esc | отменить запись, остановить звук |

### Обмен с друзьями

«Сборка и установка» → «Обмен с друзьями»:

- **Экспорт пачки…** — выбери героев (по умолчанию все), подпишись — их фразы и заметки
  уйдут в один zip. Отправить одного героя можно и из «Героев»: правый клик по карточке →
  «Поделиться фразами героя…».
- **Импорт пачки…** (или просто перетащи zip в окно) — сначала видно, что в пачке: по
  каждому герою сколько фраз новых, сколько совпадает с твоими, сколько обновлений от
  того же автора и где у вас обоих своя версия. Героя можно снять галочкой. Конфликты —
  «оставить мои», «взять из пачки» или по одной, послушав обе версии. Невыбранная версия
  уходит в дубли, так что ничего не теряется. Совпадающие фразы пропускаются сами.
- Фразы из пачки подписаны именем автора — и в заголовке фразы, и в дублях. Галочка
  «с исходниками для правок» кладёт в пачку wav с обрезкой и громкостью: друг сможет
  переобрезать запись без потерь. Последний импорт можно отменить кнопкой «Отменить импорт»
  на той же карточке — то, что ты успел поменять после импорта, останется.

После импорта пересобери и установи пак.

### Выключить мод или убрать его совсем

«Сборка и установка» → «Установить в игру»:

- переключатель **«Моя озвучка / Озвучка Valve»** — выключенный пак остаётся в игре
  (`pak01_dir.vpk.revoice`) и включается обратно мгновенно, без пересборки;
- **«Убрать из игры»** — программа удалит свой пак и вернёт озвучку Valve. То же самое
  делает «Проверить целостность файлов» в Steam.

## Как это работает

Озвучка лежит в `game/dota_<язык>/`: `pak01_dir.vpk` — оглавление (около 1 МБ), сами
фразы — в томах `pak01_000…005.vpk`. Внутри одной папки игра читает паки по порядку
номеров, поэтому `pak01` перекрыл бы любой мод. Программа собирает свой `pak01_dir.vpk`:
копия оглавления Valve, где чужие фразы по-прежнему ссылаются на тома Valve, а твои лежат
прямо в файле. Он весит пару мегабайт, а не как вся озвучка. Оригинал Valve на время
работы мода лежит рядом как `pak01_dir.vpk.off`; тома не трогаются.

Если Steam после обновления положит свой `pak01_dir.vpk`, программа покажет предупреждение
и попросит пересобрать пак — ссылки старого ведут в старые тома. Папку языка выбирает настройка озвучки игры: с английской
озвучкой моды из папки языка не загружаются — программа об этом тоже предупредит.

Звуки способностей и предметов лежат в основном паке игры (`game/dota/`), но пак из папки
языка перекрывает и их, поэтому они попадают в тот же `pak01_dir.vpk`. Свой звук играет
один раз, как оригинал; зациклен он, только если зациклен оригинал.

## Сборка из исходников

Нужен [Rust](https://rustup.rs/) (stable). На macOS — ещё Xcode Command Line Tools,
на Linux — `libasound2-dev` и `pkg-config` (Debian/Ubuntu: `sudo apt install libasound2-dev pkg-config`).

```bash
cargo run --release
```

Тесты: `cargo test`. Подробности об устройстве кода — в [AGENTS.md](AGENTS.md).
