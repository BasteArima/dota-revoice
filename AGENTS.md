# Dota Revoice — контекст для агентов

Программа для любительской переозвучки героев Dota 2: проигрываешь оригинальную
реплику, записываешь свою (или подкладываешь файл), а программа собирает из этого
VPK-мод, который игра подхватывает вместо озвучки Valve. Пользователи — автор и
его друзья (Windows, один на macOS), поэтому важна раздача одним exe без установки.

## Сборка и проверка

```bash
cargo run --release          # программа (default-run = dota_revoice)
cargo test                   # модульные + интеграционный tests/pipeline.rs
cargo clippy --all-targets   # должно быть без замечаний
cargo run --bin vsnd_spike -- [--base <pak01_dir.vpk>] [--overlay] out.vpk [--export <папка>] sounds/vo/<hero>/<line>=file.mp3
```

`example/` (выгрузка из игры) и `out/` в `.gitignore`: это контент Valve, в
репозиторий его не кладём. Тесты, которым нужен `example/`, молча пропускаются без него.

## Устройство кода (`src/`)

| Модуль | Что делает |
|---|---|
| `mp3.rs` | Разбор MPEG Layer III: кадры, частота, каналы; выкидывает ID3 и Xing/Info |
| `vsnd.rs` | Пишет `.vsnd_c` (скомпилированный звук Source 2) с mp3 внутри; достаёт mp3 или PCM обратно |
| `vpk.rs` | Чтение VPK v2 (в т.ч. многотомных и `*_dir.vpk.off`) и запись «одним файлом» |
| `pack.rs` | Сборка своего `pak01_dir.vpk` (`build_overlay`): оглавление Valve + мои фразы из `export/`, метка `dota_revoice/pack.txt` с отпечатком оглавления; `build` — полная копия одним файлом (для отладки) |
| `exchange.rs` | Пачки фраз для друзей (формат 2): экспорт выбранных героев с подписью и отпечатками (MD5 mp3), импорт в два шага — `preview` (новая / совпадает / обновление от того же автора / конфликт / не из игры) и `apply` по решениям; заменённое и отклонённое уходит в дубли, `Store::origin` помнит, от кого фраза |
| `update.rs` | Новая версия на GitHub (релизы `BasteArima/dota-revoice`) и самообновление: архив своей системы (`asset`), скачивание с прогрессом, сверка размера и SHA-256 (`digest` от GitHub), программа из zip/tar.gz, замена exe (текущий → `<имя>.old`, новый на его место), перезапуск с `--updated-from`, удаление `.old` новой версией; macOS — только ссылка. В отладке версию можно подменить `DOTA_REVOICE_VERSION` |
| `i18n.rs` | Язык интерфейса: макросы `tr!("рус", "eng")` и `trf!` (как `format!`), язык системы для первого запуска |
| `heroes.rs` | Список героев из `game/dota/pak01` (скрипты, имена, портреты PNG или DXT5/YCoCg; личности и автоматоны — отдельными `Hero` с `variant`) и каталог звуков (`Catalog`: у героя `sounds`, отдельно `items`), кеш `heroes.json`, распаковка папки звуков из пака (`extract_folder`: mp3 как есть, PCM — в wav) в `originals/` |
| `sfx.rs` | Звуки способностей (`sounds/weapons/hero/<папка>/`) и предметов (`sounds/items/`): `SoundSet` с группами по способностям/предметам, разбор имён файлов (`classify`: по началу, по словам, по уникальному слову; хвост — набор, `persona`/`automaton` — звук личности или автоматона), «Атака», «Прочее», папка героя (`hero_folder`), иконки `spellicons`/`items` в `cache/icons/` |
| `install.rs` | Установка своего `pak01_dir.vpk` (оригинал Valve → `.off`), выключение мода (`pak01_dir.vpk.revoice`), откат, переход с `pak02` прежних версий |
| `game.rs` | Поиск Steam/Доты (или папка из настроек), `AudioLanguage` из `boot.vcfg`, выбранный язык озвучки, скачанные языки, пак озвучки |
| `kv3.rs` | Двоичный KV3 v5, сжатый LZ4 (своя распаковка LZ4): распакованные куски для `vsnd::ctrl_pcm` и звуковые события `.vsndevts_c` (`sound_events`: событие → файлы) |
| `voice.rs` | Чья фраза в папке героя (`split`): герой, личность (`amp_wei_`, таблица `PERSONAS`), автоматон (`auto_`), аркана (`<x>_arc_`, `<x>_arcana_`) или набор (таблица `SKINS`); незнакомое начало — база |
| `project.rs` | `Store` — хранилище `export/` по путям ресурсов (состояние, дубли, корзина); `Project` — герой поверх него: `View` — чьи фразы (все / герой с арканами и наборами / личность / автоматон), арканы и наборы — разделами `<раздел>/<категория>` |
| `audio.rs` | symphonia (чтение), rubato (ресемплинг), cpal (воспроизведение и запись) |
| `process.rs` | Обработка записи: `shape` — шумодав (nnnoiseless) → тон (WSOLA), `amplify` — усиление → лимитер (быстро, для ползунка), громкость в LUFS (ebur128) |
| `opus.rs` | Голосовые Telegram: Ogg (`ogg`) + Opus (`opus-decoder`, чистый Rust). В debug для крейта отключены overflow-checks — см. Cargo.toml |
| `encode.rs` | mp3 через LAME (64 кбит/с, моно, 44100) + wav без потерь |
| `app/` | Интерфейс на egui: `mod.rs` — состояние и логика, `record.rs` — вкладка «Запись», `build.rs` — «Сборка и установка», `heroes.rs` — «Герои» (сетка портретов, стартовый экран; `open_sounds` открывает фразы, способности или предметы), `items.rs` — «Предметы» (сетка иконок, фильтры), `loudness.rs` — подгонка громкости всех фраз героя в фоне, `updater.rs` — окно обновления (что нового, прогресс, перезапуск) и удаление `.old`, `share.rs` — окна экспорта и импорта пачек (модальные, импорт читается в фоне, zip можно бросить в окно), `settings.rs` — «Настройки» (внизу «О программе»: версия, проверка обновлений, ссылки на GitHub), `setup.rs` — мастер первого запуска, `theme.rs` — палитра Dota (золото), шрифты, общие виджеты; `config.rs` — настройки между запусками (папки, язык озвучки) |
| `bin/vsnd_spike.rs` | Отладочная утилита сборки пака из командной строки |
| `build.rs` | На Windows вшивает `assets/icon.ico` в exe (`winresource`) |

Иконка — тот же логотип, что в шапке (золотой квадрат с микрофоном Phosphor): `assets/icon.png`
(окно, Linux), `assets/icon.ico` (exe), `packaging/macos/AppIcon.icns` (.app).

Внутри программы звук всегда моно f32 на 44100 Гц — как озвучка в игре.
Заметки к фразам («покупка BKB») хранятся там же, в `dota_revoice.json`, и ищутся поиском.
Чип в шапке показывает, что открыто (фразы героя, его способности или предметы): на «Героях» и
«Предметах» ведёт к «Записи», на остальных вкладках — к своему списку («Герои» или «Предметы»).
Над списком фраз героя — переключатель «Фразы | Способности»; чип «арканы и наборы» рядом с поиском
(`Config::show_skins`) прячет их фразы и звуки — и там, и там (у кого их нет, чипа нет). Личности и
автоматоны — свои карточки на «Героях» сразу за героем (плашка, портрет и имя из игры), чип
«личности и автоматоны» (`Config::show_variants`) прячет их из сетки. Что открыто — в настройках:
`last_folder`, `last_view`, `last_english`, `last_card`.
Нижней строки состояния нет: сообщения (`App::info` / `App::error`) всплывают плашкой снизу
по центру (`toast`) — обычные гаснут сами, ошибки висят до закрытия; состояние Доты — в
настройках, в блоке «Игра».
Шрифт — системный (Segoe UI / Arial), иконки — `egui-phosphor` (эмодзи egui рисует криво).
Раскладка экрана записи: вкладки по центру верхней панели; правка моей версии — внутри её
карточки (строки «Обрезка», «Громкость» — ползунок −20…+24 dB, «Как в оригинале», «Для всех
фраз героя…» — и «Звук»: тон и шумодав; результат шумодава и тона кешируется, ползунок
пересчитывает только усиление и пишет mp3, когда его отпустили); ряд записи симметричный: Сравнить · Оригинал · ● ·
Моя · Из файла; настройки новой записи — чипами. Не использовать `Response::scroll_to_me`
в списке: цель прокрутки egui цепляет и правую ScrollArea — смещение списка ставим вручную.
Папки: рабочая (`library`; на Windows рядом с exe, иначе «Документы/Dota Revoice»),
«Мои фразы» (по умолчанию `<рабочая>/export`), собранный пак (`<мои фразы>/build`) —
каждую можно переназначить в настройках. Старые установки (до настроек) при первом
запуске получают «Мои фразы» = прежний `export` рядом с выгрузкой и мастер не видят.
Язык озвучки для мода — `Config::voice_language` (`None` — как в игре); если он не
совпадает с `AudioLanguage` игры, сверху висит предупреждение.
Обработка неразрушающая: исходник лежит в `export/.raw/…wav`, обрезка, усиление и
шумодав — в `export/dota_revoice.json`, а `export/…mp3` каждый раз пересобирается.
Горячие клавиши: Space — оригинал, Ctrl+Space — моя версия (на macOS Ctrl+Space
по умолчанию переключает раскладку — учесть), R, C, T, L, ↑↓, N, Del, Esc.

## Что выяснено про Доту (проверено в игре)

- Реплики лежат в `game/dota_<язык>/pak01_*.vpk` как `sounds/vo/<hero>/<name>.vsnd_c`.
  Папку языка выбирает `AudioLanguage` в `game/dota/cfg/boot.vcfg`, а не язык интерфейса.
  Свои папки через `-language` и правка `gameinfo.gi` после патча июля 2026 не работают.
- Внутри одной папки архивы читаются по возрастанию номера: `pak01` перекрывает `pak02+`.
  `pak01_dir.vpk` Valve — только оглавление (~1 МБ), данные — в томах `pak01_000…005.vpk`,
  которые игра ищет по имени оглавления. Мод (с 0.4) — свой `pak01_dir.vpk`: оглавление
  Valve как есть, чужие записи ссылаются на тома Valve, мои фразы лежат внутри (индекс
  0x7FFF). Проверено в игре: звучат и свои фразы, и русские из томов. Оригинал Valve
  лежит рядом как `pak01_dir.vpk.off`. Тома не трогаем. Переименовать оригинал в `pak02`
  нельзя — он стал бы искать несуществующие `pak02_00N.vpk`.
  До 0.4 мод был полной копией озвучки в `pak02_dir.vpk` (~550 МБ); установка его убирает.
- Свой `pak01_dir.vpk` от файла Valve отличаем по заголовку: у Valve есть подпись
  (signature section 20 байт) и MD5 томов (archive MD5 section), у наших — нули
  (`vpk::is_signed`). Метка `dota_revoice/pack.txt` хранит отпечаток (размер + CRC32)
  оглавления Valve, на котором собран пак: обновление Доты меняет тома и оглавление,
  и старый пак надо пересобрать (`install::built_outdated`).
- `.vsnd_c` = заголовок ресурса (блоки REDI + DATA) + mp3-поток как есть. DATA для mp3 —
  40 байт: битовое поле формата (`0x2b1104c2` для 44100 моно), начало петли 0, число
  сэмплов (кадры × 1152), длительность, размер потока. Блок фонем (губы) не пишем.
  Valve иногда указывает на кадр больше — длина у них из исходного wav, это не важно.
- Рабочий формат мода — VPK v2 одним файлом (индекс архива 0x7FFF), секция из трёх MD5,
  без подписи. Пак на ~550 МБ одним файлом игра загружает нормально.
- Исключение — немая Марси: её 10 звуков (`sounds/vo/marci/`) лежат несжатыми, PCM 16 бит
  моно 44100. Блок DATA там старый, 68 байт: частота (u16), тип (0 — PCM16), каналы, петля,
  число сэмплов, длительность, …, со смещения 28 — размер потока; поток — сразу за заголовком.
  `vsnd::pcm_of` их читает, оригиналы распаковываются в wav. Своя версия для игры — как
  обычно mp3; что игра принимает mp3 на месте PCM-звука — ещё не проверено.
- Реплика длиннее оригинала не обрезается.
- Звуки способностей — в основном паке `game/dota/pak01`: `sounds/weapons/hero/<папка>/`
  (папка не всегда = id героя: `bristlebog` и т.п.), предметов — `sounds/items/`. Почти все —
  PCM 16 бит стерео 44100, DATA новый (40 байт): тип в битах 0–1 (1 — wav, 2 — mp3), разрядность
  в битах 2–6, каналы в битах 7–8, частота с бита 14; петля по смещению 4 (−1 — без петли).
  Проверено в игре: пак в папке языка (`dota_russian`) перекрывает эти звуки основного пака,
  mp3 на месте PCM звучит. Свой звук пишем с петлёй −1 (играет один раз); 0 — только если
  зациклен оригинал. С петлёй 0 звук BKB крутился бы всё время действия.
  Крик Акса на Berserker's Call — отдельная фраза озвучки, звук способности — свой.
- Личности (7: Anti-Mage «Вэй», Crystal Maiden «волчица», Dragon Knight и Mirana «Кровь дракона»,
  Invoker «юный», Phantom Assassin «Асан», Pudge «плюшевый») и автоматоны (5: Axe, Bristleback,
  Legion Commander, Morphling, Oracle) — в игре отдельные «герои»: `npc_dota_hero_<id>_persona1`,
  `npc_dota_hero_<id>_carnival` (имя `…:n` в `abilities_<язык>.txt`, портрет в `heroes/selection/`).
  Их фразы лежат в папке основного героя с другим началом (`amp_wei_`, `dk_davion_`/`dk_slyrak_`,
  `kidvoker_`/`kidvo_la_`, `auto_<герой>_`) и есть только в английской озвучке. Там же арканы
  (`pud_arc_`, `earth_arcana_`, `qop_arc_`…) и наборы со своей озвучкой (`jung_axe_` — Bare Knuckle,
  `helmet_…`, `…_crown_`, `imperia_`…); в русской озвучке есть немногие (`legcom_dem_`, `nev_arc_`),
  остальные у русских героев добавляются из английской. База бывает с несколькими началами
  (`drag_`/`dragon_`, `ss_`/`stormspirit_`), а самое частое начало — иногда аркана (`imperia_` у
  Venge), поэтому базу не угадываем по частоте: прячем только узнанное.
- Звуки способностей личности и автоматона — в папке героя: `*_persona*`, `kid_*` (Invoker),
  `*_automaton*`, `*_auto`.
- Новые ресурсы (`RED2` вместо `REDI`, ~40 тыс. звуков, в т.ч. фразы новых героев): блок DATA
  пустой, описание звука — в блоке `CTRL`, двоичном KV3 v5 (`05 33 56 4B`), сжатом LZ4; поток —
  сразу за заголовком (первое u32 файла — размер заголовка). mp3 узнаём по самому потоку, у PCM16
  (387 звуков: часть способностей и предметов) частоту и каналы `vsnd::ctrl_pcm` находит в
  распакованном KV3 по числам (частота; сэмплы × каналы × 2 = размер потока), без разбора KV3.
  Метка `.source` у распакованных оригиналов помнит версию распаковки (`EXTRACT_VERSION`).
- Несжатый звук бывает начат с тишины `FF FF` — это похоже на кадр mp3 (135 звуков, напр.
  `grimstroke/ink_swell_cast`). Поэтому распаковка сначала пробует PCM (`pcm_of` строг: у старого
  DATA с типом 0 сэмплы × каналы × 2 ровно равны размеру потока — так у всех 770 таких в игре),
  потом mp3; файл с другим расширением от прежней распаковки удаляется.
- Иконки: формат 28 в `.vtex_c` — несжатый BGRA8888 (часть иконок предметов), 2 — DXT5.
- Предметы: подпись новых (нейтральных) — с `:n` (`DOTA_Tooltip_ability_item_kobold_cup:n`).
  Таблицы «предмет → звук» в файлах игры нет: предмет вызывает из кода (`server.dll`) событие,
  а событие → файлы — в `soundevents/game_sounds_items.vsndevts_c` (блок DATA, KV3:
  `DOTA_Item.BattleFury` → `blade_fury.vsnd`). Поэтому сверяем имена: имя файла, а если не
  вышло — имена событий, которые его играют; id и подпись предмета, имена его способностей из
  описания (`<h1>Passive: Combo Breaker</h1>` у Aeon Disk, только уникальные), сокращения
  (слово звука — начало слова предмета: `rune_regen`, `mek_cast`) и таблица
  `sfx::ITEM_ALIASES` для рабочих имён (`star_emblem` — Solar Crest, `faerie_spark` — Faerie
  Fire; сверены по соседним строкам в `server.dll`). Один файл бывает у нескольких событий
  (`wraith_totem_spawn` — Wraith Pact и Roshan's Banner) — в списке он у одного предмета.
  Иконка бывает названа чуть иначе предмета (`bottle_invisibility` у `bottle_invisible`).
  В «Прочих» остаются звуки карты (лотосовые пруды, фонтан опыта), нейтральный лут, краска для
  реки, звуки событий — их нет в событиях предметов.
- Имена способностей — `DOTA_Tooltip_ability_<id>` в `abilities_<язык>.txt` (регистр бывает
  разный), список — `"AbilityN"` в скрипте героя; иконки — `panorama/images/spellicons/<id>_png.vtex_c`
  (DXT5 128×128) и `panorama/images/items/<id>_png.vtex_c` (DXT5 или BGRA8888, 88×64).
- Dota 2 Mod Manager пользователя занимает в `dota_russian` номера 07, 30–44, 64
  (список в `dota2modmanager.json`) — чужие файлы не трогать; наш файл — `pak01_dir.vpk`.
- Source 2 Viewer держит паки открытыми: перед переименованием попросить его закрыть.

  `trf!("Записано {n}", "Recorded {n}")`. Строку без перевода не добавлять; `tr!` с `{…}` не соберётся.
  Термины в английском: фраза — line, озвучка — voice-over, пак — pack, пачка фраз — line bundle,
  дубль — take, «Мои фразы» — My lines, рабочая папка — workspace folder.
- Микрофон пользователя без спроса не включать на запись (для проверок — синтетический звук).
